# Star Studio

React CSR + Three.js로 만든 불꽃 제작·공연 편집 프로토타입입니다. 한국어와 영어를 지원합니다.

## 1분 불꽃축제

보관함의 **화려한 1분 공연 불러오기**를 누르고 **크게 감상 → 재생**을 선택하세요. 발사대 20개, 보관함 불꽃 11종, 독립 큐 175개로 구성됩니다. 마지막 잔광까지 60초이며, **Escape**로 편집 화면에 돌아옵니다. 현재 공연은 실행 취소로 복원할 수 있습니다.

- 0–12초: 좌우 웨이브와 대칭 발사
- 12–30초: 하트·고양이·사과·컵, 낮은 보조 불꽃
- 30–42초: 양방향 연사와 높이 변화
- 42–60초: 황금빛 비, 20대 연발, 다섯 색 피날레와 중앙 대형 불꽃

[공연 JSON](examples/midnight-fantasy.fireworks.json)도 바로 열 수 있습니다. JSON에는 프레임 대신 설정과 트리거만 담겨 있습니다. 공연을 다시 불러오면 항상 원본 템플릿의 새 복사본을 만듭니다. 보관함 불꽃이나 큐에서 수정해도 원본과 다른 복사본은 바뀌지 않습니다.

기본 5가지에 **하트·고양이·사과·컵**을 더해 모양 프리셋은 총 9가지입니다. 새 모양은 윤곽 길이에 따라 발광체를 균등 배치하고, 각 점의 중심으로부터의 거리도 보존해 확장합니다. 정면에서 가장 잘 보이는 평면 패턴이며, 낮은 점 개수에서는 얼굴·손잡이 같은 세부가 줄어듭니다. 아이콘과 실제 발광체 배치는 같은 윤곽 데이터를 사용합니다.

## 이미지 캐릭터 불꽃

보관함의 **캐릭터 프리셋 → 2D 평면 / 3D 입체**에서 하트 모자, 헬로키티, 쿠로미, 마이멜로디, 폼폼푸린, 시나모롤, 포차코를 선택합니다. 총 14가지 조합이며, 기존 모양 프리셋도 그대로 사용할 수 있습니다.

- **2D 평면**: 외곽선·내부 색면·표정과 장식·별빛 테두리의 4개 레이어, 발광체 3,192개입니다. 모든 입자가 같은 평면에서 퍼집니다.
- **3D 입체**: 위 구성에 입체 볼륨 레이어를 추가한 5개 레이어, 발광체 4,216개입니다. 실루엣 안쪽으로 갈수록 부풀어 오르는 앞면과 뒷면, 그 사이의 입자가 두께를 만듭니다. 기본 회전은 −22°이며 캔버스를 드래그하면 옆모습을 확인할 수 있습니다. 단일 이미지에서 만든 둥근 입체 표현으로, 원본 캐릭터의 정식 3D 모델은 아닙니다.
- 레이어 표시를 끄거나 **선택 레이어**로 각 부분을 살펴볼 수 있습니다. 내부 색면의 발광체 수는 최대 4,096개까지 조절합니다. 정렬을 유지하려면 캐릭터 레이어의 퍼짐·회전·지연을 함께 맞추세요.
- 은색 발광체는 이미지 팔레트를 유지하고, 다른 처음 색은 해당 레이어를 물들입니다. 검정은 빛을 낼 수 있도록 파랑·보라로 표현합니다. 작은 눈·코·리본 색은 별도 샘플링 비중을 확보합니다.

`src/domain/character-art.json`은 첨부 원본에서 추출한 색상 마스크입니다. 포스터의 제목·이름·배경은 제외하고 흰 얼굴과 하이라이트를 보존합니다. 아이콘과 2D/3D 입자 모두 이 마스크를 사용하며, 실행 시 원본 이미지 파일이나 네트워크가 필요하지 않습니다. Pillow가 있는 환경에서 `python scripts/prepare-character-art.py --hat <첫번째.webp> --sheet <두번째.webp>`로 다시 생성할 수 있습니다. 좌표·색상은 실행 시 결정적으로 샘플링하며 JSON 저장은 기존 레이어·패턴·시드 구조를 사용합니다.

## 캐릭터 순차 공연

보관함의 **캐릭터 순차 공연 불러오기 → 크게 감상 → 재생**을 선택하세요. **캐릭터 퍼레이드**는 중앙 발사대 1개에서 캐릭터만 총 14발을 발사하는 약 95초 공연입니다. [공연 JSON](examples/character-parade.fireworks.json)을 직접 열어도 같은 구성을 사용할 수 있습니다.

- 먼저 **2D 7종**, 이어서 **3D 7종**을 보여줍니다. 각 구간의 순서는 하트 모자 → 헬로키티 → 쿠로미 → 마이멜로디 → 폼폼푸린 → 시나모롤 → 포차코입니다.
- 캐릭터 프리셋의 외곽·면·표정·장식·테두리를 그대로 사용합니다. 앞 불꽃의 잔광이 모두 끝난 뒤 0.65초 이상 쉬고 다음 발사를 시작하며, 2D에서 3D로 넘어갈 때는 1.5초를 더 쉽니다.
- 실제 레이어 수명에서 발사 간격을 계산하므로 캐릭터끼리 겹치지 않습니다. 현재 기본 프리셋 기준 첫 발사는 0.5초, 3D 시작은 약 48.7초, 마지막 잔광 종료는 약 94.7초입니다.
- 불러올 때마다 보관함 불꽃과 큐의 새 복사본을 만듭니다. 큐를 수정해도 보관함이나 원본 프리셋에 영향을 주지 않으며, 실행 취소로 이전 공연을 복원할 수 있습니다.

## 실행

Node.js 22.12 이상에서 실행합니다. 별도 서버 계정은 필요하지 않습니다.

```sh
npm ci
npm run dev
```

```sh
npm run lint
npm run build
npm run preview
```

## 사용 흐름

1. **불꽃 만들기**: 모양 프리셋을 눌러 보관함에 새 불꽃을 만듭니다. 각 불꽃은 최대 8개 레이어를 가지며, 레이어마다 패턴·발광체·지연·폭발 속도·감속을 조절합니다.
2. **발광체**: 선택 레이어에 프리셋을 복사하거나 색·크기·색 전환·수명·밝기·잔광을 직접 편집합니다. 다른 레이어나 불꽃은 바뀌지 않습니다.
3. **발사**: 폭발 높이와 상승 시간을 정합니다. 높이는 가상 무대 단위 `u`, 시간은 초입니다.
4. **공연 편집**: 보관함의 불꽃을 발사대 행의 원하는 시각으로 드래그하거나 `큐 추가`를 사용합니다. 배치할 때 불꽃의 전체 설정을 복사합니다.
5. **개별 큐**: 발사 시각·높이·상승 시간·발사대를 바꾸거나 `이 큐의 불꽃 상세 편집`으로 모든 레이어를 수정합니다. 보관함과 다른 큐에는 영향을 주지 않습니다. 첫 폭발 시각은 발사 시각 + 상승 시간입니다.
6. **순차 배치**: 사용할 불꽃들을 선택한 순서와 발사대의 좌우 순서에 따라 순환 배치합니다. 시작·간격·전체 개수를 지정하며 한 번의 실행 취소로 되돌립니다.

불꽃과 큐는 복사·붙여넣기·복제를 지원합니다. 복제는 현재 큐와 같은 시각에 만들고, 붙여넣기는 선택 발사대의 현재 재생 시각에 만듭니다. 입력 칸 밖에서 `Ctrl/Cmd+C`, `Ctrl/Cmd+V`, `Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z`를 사용할 수 있습니다. 드래그는 0.1초 단위이며 숫자 입력으로 더 정밀하게 맞출 수 있습니다. 내부 시간은 1/120초 정수 tick으로 반올림합니다.

겹치는 큐는 줄을 나눠 표시합니다. 타임라인 확대, 내부 가로·세로 스크롤, 발사대 이름 고정을 지원합니다. 터치 화면에서는 `큐 추가`와 상세 필드로 모든 배치 기능을 사용할 수 있습니다. 도움말 아이콘은 마우스, 키보드 포커스, 클릭으로 열고 Escape로 닫습니다.

## 저장과 호환성

- 문서 형식은 `star-studio/2`, 시각 모델은 `visual-star/2`입니다.
- JSON은 불꽃 설계, 발사대, 큐의 독립 설계, 시드와 입력만 저장합니다. 계산된 프레임은 저장하지 않습니다.
- [새 기본 공연](examples/first-show.fireworks.json)을 열어 현재 예제를 사용할 수 있습니다.
- [이전 형식 예제](examples/legacy-v1.fireworks.json)도 가져올 수 있습니다. 공유 발광체·효과를 독립 불꽃과 큐 설정으로 변환합니다. 새 폭발 모델이므로 예전 버전과 화면이 완전히 같지는 않습니다.
- 자동 저장은 같은 브라우저·주소에서 편집 500ms 후 기록합니다. 이전 v1 자동 저장 키는 유지합니다. 읽지 못한 v2 데이터는 복구 키에 백업한 뒤 예제를 엽니다.
- 언어는 별도 브라우저 환경설정입니다. 사용자가 지은 이름과 저장 데이터는 언어 전환으로 수정하지 않습니다.

## 상태와 렌더링

| 소유자 | 관리하는 정보 |
| --- | --- |
| `documentStore` | 불꽃·레이어·발사대·큐와 수정 이력 |
| `editorStore` | 화면, 선택, 편집 대상, 앱 내부 클립보드 |
| `localeStore` | 한국어/영어 선택 |
| `PlaybackClock` | 재생 시각·구간·재생·반복 여부 |
| `ParticleEngine` | 파생 궤적, 현재 입자 버퍼 |
| `ThreeViewport` | 카메라, GPU 자원, 장면 |

`CanvasHost`는 화면 전환에도 유지됩니다. 시간·문서·언어를 직접 구독하지 않으며 작은 UI 자식만 필요한 상태를 구독합니다. `StudioSession`이 엔진과 뷰포트에 변경을 전달합니다. 언어 전환은 Canvas 접근성 이름만 바꾸고 엔진 입력을 바꾸지 않습니다. 시간 출력은 10Hz, 작은 탐색 막대는 20Hz이며 파티클은 React 상태를 거치지 않습니다.

감상 화면도 `editorStore`의 UI 설정입니다. 기존 Canvas·카메라·재생 시각을 유지하고, 숨겨진 타임라인은 구독을 해제합니다. 공연 JSON이나 엔진 입력에 감상 모드를 저장하지 않습니다.

개발 주소에 `?diagnostics`를 붙이면 재생 전후 React 커밋 수를 비교할 수 있습니다.

## 범위

발광체 한 개를 논리 단위로 계산합니다. 초기 속도 강조, 확장 감속, 늦은 발광 소멸, 경로상의 잔광을 절대 시각에서 다시 평가하여 되감기와 부분 편집을 지원합니다. 최대 보관함 불꽃 64개, 레이어 8개/불꽃, 발사대 32개, 큐 256개, 발사 시각 120초까지입니다. 동시에 표시하는 점은 131,072개까지이며 초과 시 잔광 일부를 생략하고 안내합니다.

현재 엔진은 TypeScript입니다. Rust/Wasm·Worker, 개별 발광체 좌표 배치, 연기·바람, 음악 동기화, 카메라 키프레임은 아직 구현하지 않았습니다. `SimulationEngine` 인터페이스가 교체 경계입니다. 외형 프로필은 예술적 모델이며 실제 화약 조성이나 제조·발사 성능을 계산하지 않습니다.
