이번 외부 조사는 [타임라인 모델 정리](/Users/carlos-yang/dev/fireworks-simulator/research/timeline-runtime-model.ko.md)와 분리된 작업이다. 외부 결과의 제안과 검증된 문헌 사실을 구분해 읽어야 한다.

**수신 방법과 보존 범위.** ChatGPT 응답에 지정한 Markdown 첨부가 생성되었고, 파일 미리보기에서 9개 본문 절과 참고문헌까지 확인했다. 인앱 브라우저의 다운로드 동작은 로컬 파일 경로를 제공하지 않았고, 일반 콘텐츠 내보내기와 해당 문서 자산의 저장 기능도 지원되지 않았다. 따라서 파일 미리보기의 표시된 본문·표·링크·코드 블록을 읽어 Markdown으로 재구성했다. 서버 파일을 바이트 그대로 내려받은 원본은 아니다. 본문의 주장과 문장을 편집하지 않았으며, 로컬 의견은 검토 파일에만 적었다.

수신본은 15,942자, 332줄, UTF-8 30,238바이트이며 표 5개와 JSON 코드 블록 1개가 있다. 브라우저에서 구성한 Markdown과 저장한 파일의 글자 수·줄 수·본문 체크섬이 일치했다. 원문의 조사일 2026-09-05는 유지했다. 참고문헌의 자동 링크 등 표시 형식은 미리보기에서 가져온 형태다.

저장한 수신본 SHA-256: `80d6db3edfc9db5c53c6c065c484ad233997e79a10ad0efc7ea09fb42ace6962`. 이는 로컬 수신본의 지문이며 서버 원본과의 동일성을 증명하는 값은 아니다.

**조사 질문은 최소 의미 단위와 좌표 표현이다.** 원료 미세 입자, 성형된 발광체, 불티·액적, 집합 모델을 구별하고, 질량 단위와 계산 객체 단위가 다른 이유를 설명하도록 요청했다. 공중 구형, 긴 꼬리, 분기, 연속 방출 효과에 대해 편집 단위·계산 단위·렌더 단위를 따로 비교하도록 했다.

가상 배치는 명시적인 좌표 목록, 분포 규칙과 seed, 분포에 일부 override를 더한 혼합 방식을 비교하도록 했다. 정규화, local→effect→launcher→world 변환, 방향, 샘플링 편향, stable ID, 부분 편집의 지속성, N개 객체와 K개 예외의 데이터 규모를 다루도록 요청했다.

정확도는 정면의 형태, 시간 변화, 다른 시점의 일관성, 반복 재생의 재현성으로 나눠 분석하도록 했다. 단안 영상·장노출 사진·알 수 없는 카메라 노출에서 복원할 수 없는 항목도 명시하도록 했다.

**근거 확인 조건을 함께 전달했다.** 원 논문·저자 공개본·학회와 출판사 자료를 우선하고 실제 확인 범위를 전문의 해당 부분·초록·검색 추출로 구분하도록 했다. DOI·직접 링크·확인한 절이나 그림 번호를 요구했으며, 확인하지 못한 값이나 유일한 최소 입도·그램 기준을 추정하지 않도록 했다.

실제 폭발물의 제조·배합·공정 조건, 점화 작업 조건, 실물 용기의 충전 배치와 조립 도면은 제외했다. 가상 효과의 시각 속성과 정규화된 좌표만 분석하도록 했다. Wasm·GPU 성능 최적화는 후속 구현에서 다루므로 이번 조사에서 비중을 두지 않도록 했다.
