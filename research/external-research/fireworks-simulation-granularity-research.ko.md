# 불꽃축제 웹 시뮬레이터: 최소 의미 단위와 가상 좌표 표현 후속 조사

조사일: 2026-09-05
대상: 관람용 컴퓨터그래픽스(CG) 효과의 편집·재생·검증

## 1. 결론과 근거의 범위

**조사한 문헌에서는 모든 효과에 통용되는 ‘정확한 최소 입도’나 ‘그램당 객체 수’를 정할 근거를 확인하지 못했다.** 권장 방향은 **편집할 의미 단위, 운동 상태를 갖는 단위, 화면에 그리는 단위를 분리**하고, 효과마다 필요한 수준만 선택하는 것이다.

원본은 이벤트와 효과 정의이며, 타임라인 → 가상 발사대 → 효과 인스턴스의 프레임 상태는 런타임이 계산한다. 정규화된 가상 좌표만 다루며 실제 배합·제조·충전·작업 조건이나 제작 결과 예측은 제외한다.

**[문헌]**은 확인한 사실, **[설계 추론]**은 응용 제안, **[검증 가설]**은 시험할 판단이다. 새 시뮬레이션 실험은 수행하지 않았다. 출처별 열람 범위는 참고문헌에 기재했다.

### 먼저 지정된 여섯 논문에서 확인한 것

**Reeves, 1983 — [문헌].** §2는 생성·속성·운동·소멸·렌더링을 나누며, §2.6은 입자 자체가 다른 입자계일 수 있는 계층을 설명한다. §2.1은 화면 점유 면적에 따른 생성량 조절도 제시한다. 이는 CG 입자를 자연계의 고정 크기 입자와 일대일 대응시키는 정의가 아니다. §2.2와 그림 1은 생성 영역의 원점·방향을 세계 좌표와 구별한다. [R1]

**Zhao 등, 2009 — [문헌: 초록].** 3D 메시를 점으로 표본화하고 역동역학으로 목표 형상을 만드는 형상 제약 애니메이션, 군집을 이용한 다단계 효과, 추가 무작위 입자를 설명한다. 목표 모양 제어의 선례이지 실제 배치의 결과 예측 근거는 아니다. 전문은 미확인이다. [R2]

**Tang 등, 2012 — [문헌: 초록].** 외부 XML 데이터와 실시간 입자계 구현을 설명한다. 초록은 실행 구조와 성능 중심이며 편집 객체의 의미와 최소단위는 확인되지 않는다. XML 사용만으로 특정 스키마나 물리적 정확성을 정당화할 수 없다. [R3]

**Memmel 등, 2022 — [문헌: 검색 추출].** PubMed 초록 검색 추출은 색뿐 아니라 분기가 불티의 시각적 외관에 중요하다고 명시하고, ACS 본문 검색 추출에는 연속 분기 사례가 나타난다. 전문·그림·영상은 미확인이다. 외관에 색 이외의 분기 차원이 있다는 제한적 근거로 사용한다. [R4]

**Inoue, 2018 — [문헌].** §3.2와 그림 7은 하나의 액적이 여러 자식 액적으로 분리되는 고속 관측과 가지 모양의 대응을 설명한다. §4는 깊이를 포함한 구조를 조사하기 위한 다중 카메라 재구성도 언급한다. 특정 현상의 관찰을 모든 공중 효과의 공통 미세단위로 일반화해서는 안 된다. [R5]

**矢花·藤澤·三河, 2022 — [문헌].** §2와 그림 1은 낙하산의 강체, 연결 요소, 질점, 연기의 격자 유체를 결합한다. §4는 방향 없는 질점 모델로는 연기 방출 방향 변화가 표현되지 않는 한계를 적는다. 한 효과 안에서도 관찰할 현상에 따라 서로 다른 상태 단위가 필요함을 보여준다. 이 전체 모델을 야간 불꽃의 기본값으로 권하는 것은 아니다. [R6]

## 2. 무엇을 ‘하나’로 셀 것인가

아래는 **개념 구분과 설계 제안**이다. CG의 `particle`이라는 이름만으로 실물 대응을 판단하지 않는다.

| 구분 | 무엇을 가리키는가 | 관람용 모델에서의 취급 | 그 자체로 알 수 없는 것 |
| --- | --- | --- | --- |
| 원료의 미세 입자 | 발광 현상의 재료를 구성하는 미시적 입자 | 기본 편집·운동 객체로 삼지 않음 | 화면의 점 수, 궤적 수, 효과의 최소 해상도 |
| 성형된 발광체, star | 독립적으로 빛을 내며 이동하는 실물 발광체 | 대응되는 가상 발광체를 궤적·수명·외관의 주체로 둘 수 있음 | 한 발광체를 렌더 입자 하나로 충분히 표현할 수 있는지 |
| 불티·액적, spark/droplet | 분리되어 이동·발광하는 개체 또는 그것이 보이는 현상 | 분기·독립 운동을 볼 필요가 있을 때 자식 운동 노드로 표현 | 모든 불티가 액체인지, 모든 불티가 star에서 떨어진 것인지 |
| 집합·분포 모델 | 여러 가상 개체의 공통 분포·외관·생성 규칙 | 사용자가 한 번에 조절하는 그룹이나 생성기 | 집합 하나가 실물 하나라는 대응 관계 |
| 렌더 표본 | 점광원, 스프라이트, 선분, 리본의 정점 등 | 운동 결과를 화면에 표현하는 표본 | 실물 입자 수나 실제 발광체의 크기 |

**g은 질량 단위이고 N은 모델의 개체 수다.** 객체 하나가 발광체·불티 집합·장식 중 무엇인지부터 다르므로 질량만으로 ‘정확한 N’을 정할 수 없다. 질량에서 객체 수가 자동 결정된다는 인터페이스는 피한다.

객체 세분도·적분 시간 간격·곡선 표본 간격·픽셀 크기도 별개다. 리본 정점 증가가 운동 모델의 상세화를 뜻하지 않는다.

**[설계 추론]** 고정할 것은 물리 크기가 아니라 `ID·생성 시점·부모 관계·운동·외관 프로필`이다. 최소 의미 단위는 사용자가 독립적으로 바꾸고 그 변화를 관찰·검증하려는 대상이다.

## 3. 편집·운동·렌더 단위는 같아야 하는가

**같게 만들 필요가 없다.** 꼬리 한 항목을 부모·자식 운동과 여러 선분으로 구현하거나, 먼 거리의 여러 개체를 합쳐 그릴 수 있다. 아래는 검증할 시작점이다.

| 효과 | 편집 가능한 최소 의미 단위 | 운동 상태를 갖는 단위 | 렌더 단위 | 근거와 한계 |
| --- | --- | --- | --- | --- |
| 일반적인 공중 구형 효과 | 분포 그룹 + 선택한 개별 가상 발광체 | 독립 궤적과 수명을 갖는 발광체 | 발광 스프라이트, 필요한 경우 짧은 궤적 | 입자 속성 분리 [R1]. 도구 용어에서도 구형 효과의 꼬리 유무를 구별 [T2] |
| 긴 꼬리 효과 | 부모 발광체 + 꼬리 프로필 | 부모 경로; 독립적으로 퍼지거나 남는 불티만 자식 상태 | 시간 표본 리본 + 선택적 불티 스프라이트 | 꼬리 외관 조절 사례 [T1]. 리본만으로 충분한 거리는 미검증 |
| 분기 효과 | 가지 생성 규칙 + 수정할 가지/자식 | 분기 시점에서 생성되는 자식 궤적 | 연결 선분, 각 가지의 발광점 | 계층 표현 [R1], 액적 분기 관측 [R5]. 관측된 분기를 단순 흔들림으로 대체하면 구조가 달라짐 |
| 연속 불티 효과 | 생성기 + 시간별 방출·외관 곡선 | 시간에 걸쳐 태어나는 불티 또는 대표 집합 | 불티점, 짧은 선분, 원거리 집합 표현 | 연속 생성 틀 [R1], 제품의 연속 방출 구성 [T1]. 집합화 시 개별 궤적 편집은 제한 |

### 꼬리는 서로 다른 세 현상을 구별해야 한다

**[설계 추론]** ‘긴 빛줄기’는 부모 경로를 그린 리본, 독립 발광 개체의 집합, 노출 중 이동의 누적일 수 있다. 셋을 혼동하면 카메라·재생 속도 변경에 잘못 반응한다. 노출에 따른 운동 흐림은 영상 형성의 문제다. [R10]

꼬리 개체는 부모 소멸 후에도 남거나 상대 운동으로 부모 경로에서 벗어날 수 있다. 차이가 식별되면 자식 상태가 필요하다. 식별되지 않으면 경로 이력과 밝기 감쇠를 가진 리본을 후보로 삼되, 관람용 대체 표현으로 표시한다.

분기는 부모의 위치·속도·나이를 읽는 생성 사건으로 표현한다. 생성 순번·부모 관계를 보존하되 모든 세대를 상세 계산하지는 않는다. 특정 장식 불티를 직접 편집할 때 지속 ID를 가진 객체로 승격할 수도 있다.

**[검증 가설]** 일반 관람에서는 발광체·외관 곡선·꼬리를 기본으로, 분기 등이 두드러질 때 자식 노드를 추가하면 충분할 수 있다.

## 4. 가상 좌표와 부분 편집 모델

### 4.1 세 가지 저장 방식 비교

| 방식 | 편집성과 재현성 | 주요 비용·위험 |
| --- | --- | --- |
| 모든 좌표를 명시 저장 | 개별 위치를 정확히 고정하고 다른 편집기로 옮기기 쉬움 | 원본 O(N). 밀도나 분포 전체를 바꾸려면 별도 편집 연산 필요. 좌표만으로 운동 재생이 고정되지는 않음 |
| 절차적 분포 + seed | 적은 매개변수로 전체 구형·고리·영역을 조절하기 쉬움 | 생성 알고리즘이 바뀌면 같은 seed도 다른 배치. 순차 난수만 쓰면 일부 변경이 이후 개체를 흔들 수 있음 |
| 절차적 분포 + 일부 override | 전체 조형과 국소 수정을 함께 유지. 희소 수정이면 원본이 작음 | ID·버전·재생성 정책이 없으면 수정 대상이 바뀌거나 사라짐. K가 N에 가까워지면 저장 이점 감소 |

**[설계 추론]** 하이브리드를 기본으로 명시 좌표 고정도 제공한다. 생성기 버전과 ID 계약이 전제다.

### 4.2 좌표계 계약

**다음은 프로젝트 규약 제안이다.** 오른손 좌표계에서 +X는 오른쪽, +Y는 위, +Z는 자산 정면이다. 기본 카메라는 +Z 쪽에서 −Z를 바라본다. 가상 발사대의 조준 축은 로컬 +Y로 명시한다. 고리의 기본 평면은 XY, 법선은 +Z이며 회전으로 방향을 바꾼다.

중심과 기준 반경 1을 고정하고 세계 공간은 `sceneUnit`을 쓴다. 균일 크기 배율과 의도적 비균일 변형을 구별한다. 개별 수정 때 전체를 재정규화하거나 경계를 넘는 override를 자동 축소하지 않는다.

열벡터를 사용하면 초기 위치의 변환 계약은 다음과 같다.

```text
p_world = M_world←launcher · M_launcher←effect · M_effect←local · p_local
```

`local`은 분포·가지 생성기의 좌표, `effect`는 재사용 효과 자산의 좌표, `launcher`는 이벤트가 참조한 가상 발사대, `world`는 관람 장면이다. 변환은 오른쪽부터 적용하고 각 행렬 내부의 순서도 `T·R·S`로 고정한다. 회전 저장 순서는 단위 쿼터니언 `[x,y,z,w]`로 명시한다. 방향에는 평행이동을 적용하지 않고 회전 후 정규화한다. 속도 크기는 효과의 공간 배율과 재생시간 배율에 맞춰 별도로 환산한다.

발사대 변환은 **효과 시작 때 스냅샷**으로 잡아 이후 회전이 비행 중인 개체를 끌고 가지 않게 한다. 자식은 생성 시점의 부모 자세를 읽고 부모 관계는 기록하되 운동은 분리한다. 계속 붙어 있는 연출은 별도 모드다.

### 4.3 분포는 위치·방향·목표 중 무엇인가

좌표 배열·생성기에 `initial-position`, `direction-sample`, `target-position`의 **역할**을 붙인다. ‘구면’만으로는 초기 위치·운동 방향·도달 목표 중 무엇의 분포인지 알 수 없다.

**[문헌·수학적 적용]** PBRT는 면적 기준의 균일 표본과 단순한 매개변수 균일 표본을 구별한다. 구면에서는 극각을 균일하게 뽑는 방법이 극 부근의 밀도를 높이고, 원판에서는 반지름을 균일하게 뽑으면 중심 쪽에 몰린다. [R9] +Y를 극축으로 택한 단위 구면 표본은 다음과 같이 만들 수 있다.

```text
u, v: 서로 독립인 [0,1) 표본
h = 1 - 2u,  φ = 2πv
q = (sqrt(1-h²)cosφ, h, sqrt(1-h²)sinφ)
```

구의 **표면**과 **부피**도 구별한다. 부피 균일 분포는 반지름의 누적 부피가 r³에 비례하므로 별도의 독립 표본 w에 대해 `r = w^(1/3)`을 사용한다. 고리 둘레의 균일 표본은 각도로, 원판 면적의 균일 표본은 `r = sqrt(u)`로 구분한다.

메시의 정점을 그대로 사용하면 메시 분할 밀도가 곧 발광점 밀도가 된다. 면적 균일, 부피 균일, 특징 강조는 다른 목표다. Cui 등의 §5.1과 그림 8은 복잡한 형상을 드러내기 위한 곡률 기반 비균일 표본을 보여준다. [R7] 특징 강조는 모양을 잘 읽히게 하는 예술적 선택일 수 있지만 ‘균일한 분포를 더 정확하게 복원한 것’이라고 부르지는 않는다.

### 4.4 stable ID와 수정의 지속성

**[문헌]** Salmon 등의 §5.1은 객체의 안정된 식별자와 시간을 난수의 키·카운터에 대응시키는 방식을 설명한다. [R8] **[설계 추론]** 이를 편집에 적용하여 난수를 다음과 같이 개체와 속성별로 분리한다.

```text
random = F(seed, componentID, birthOrdinal, propertyChannel, eventOrdinal)
```

`birthOrdinal`은 정렬된 배열의 현재 인덱스가 아니라 생성 때 부여한 영구 순번이다. 위치 해시를 ID로 쓰면 이동할 때 정체성이 바뀌므로 피한다. 자식 ID는 부모 ID·생성 사건 ID·자식 순번으로 구성한다. 위치·외관·시간 난수 채널을 분리하고 자산 ID와 수정 버전도 구분한다.

N과 독립인 표본열의 앞 N개를 쓰면 증원해도 기존 점을 유지할 수 있다. 전체 간격 재최적화나 N 의존 배치는 기존 점을 움직일 수 있다. **seed와 ID만으로 같은 대상·같은 좌표가 모두 보장되지는 않는다.** 균등 간격과 위치 보존의 선택을 드러내야 한다.

override는 `절대 local 위치로 고정`과 `생성된 local 위치에 오프셋 추가`를 구별한다. 전자는 자산 안의 고정 위치를 유지하고 후자는 바뀐 분포를 따라간다. 기본값·그룹 수정·개별 수정을 적용하는 우선순위도 고정한다. 위치만 바꿀 때 방향까지 다시 계산할지는 별도 결합 옵션으로 둔다.

N 감소로 비활성화된 ID의 수정은 휴면 상태로 남기거나 사용자에게 고아 수정으로 표시한다. 삭제 시 남은 개체를 재번호화하지 않는다. 생성기·seed·토폴로지 변경 시 최근접 점으로 수정을 몰래 옮기지 말고 재연결이나 좌표 고정을 요구한다. 참조 자산의 버전도 고정하여 공용 자산 수정이 과거 쇼를 바꾸지 않게 한다.

## 5. 초기 위치만으로 최종 형태가 정해지지 않는 이유

**[설계 추론]** 현상을 설명하기 위한 가장 단순한 가상 운동만 보아도 다음과 같다.

```text
τ = t - birthTime_i
p_i(t) = p_i(0) + v_i(0)τ + ½a_iτ²
```

일정 가속도의 CG 예시이지 실물 예측식은 아니다. 같은 초기 위치도 운동 방향·상대 속도에 따라 얇은 구면, 두꺼운 분포, 비대칭 형상으로 펼쳐진다. 감속·흐름·분기도 영향을 준다.

보이는 형태는 위치 전체가 아니라 **그 시점에 보이는 개체의 부분집합**이다. 같은 궤적도 발광 시작의 지연, 밝기 곡선, 수명, 꼬리 개체의 잔존 시간에 따라 다르게 보인다. 빠른 개체가 먼저 어두워지면 화면의 바깥 윤곽은 운동상의 바깥 경계와 다르다. 위치만 맞추면 펼침과 소멸은 틀릴 수 있다.

**[검증 가설]** 같은 가지의 방향·시간·밝기를 모두 독립 난수로 만들면 가지가 흐트러질 수 있다. 필요한 상관관계는 관측으로 확인하고 특정 재료와 자동 연결하지 않는다.

### 관측을 닮게 만드는 모델과 목표 강제 제어

**관측 지향 모드**는 궤적·펼침·생성과 소멸의 통계를 비교해 조절한다. 목표 형상을 향해 끌어당기는 숨은 제어는 두지 않는다. 단순화된 운동이므로 이를 실물의 예측 모델이라고 부르지 않는다.

**예술적 형상 모드**는 정해진 시각의 위치 또는 화면 투영을 목표로 운동을 역산·보정한다. Zhao의 초록과 Cui의 §5.2는 이런 목표 지향 방식의 직접적인 선례다. [R2][R7] 특정 순간의 모양을 잘 맞추는 것은 유용하지만, 그 성과를 자연 현상의 재현 정확성과 합산하지 않는다.

카메라에 대해서도 `3D 공간 목표`와 `특정 시점의 화면 목표`를 구분한다. 3D 고리를 옆에서 보면 납작하게 보이는 것이 정상이다. 다중 시점 일관성이란 모든 시점에서 같은 2D 모양이 보인다는 뜻이 아니라, 하나의 동일한 3D 장면으로 설명된다는 뜻이다. 카메라를 따라 항상 정면을 보이는 패턴은 별도의 연출 모드다.

## 6. 저장 원본·재생 상태·렌더 장식과 데이터 규모

**[설계 추론]** 세 데이터 수명을 분리한다.

| 층 | 저장·유지할 내용 | 규모의 기준 |
| --- | --- | --- |
| 편집 원본 | 이벤트, 자산 참조와 버전, 분포·seed, 곡선, override | 명시 좌표 O(N), 절차식 O(P), 하이브리드 O(P+K) |
| 재생 상태 | 현재 살아 있는 운동 노드의 위치·속도·나이·생성 사건 | O(A(t)); 독립 노드의 단순 갱신도 O(A(t)) |
| 렌더 장식 | 꼬리 이력, 선분 표본, 스프라이트, 화면상의 발광 효과 | 이력 H개씩이면 O(A(t)H), 별도 장식 D(t)는 추가 |

N은 생성할 기본 가상 개체 수, K는 개별 수정 레코드 수, P는 생성기·곡선 설명 크기, A(t)는 자식을 포함해 현재 살아 있는 운동 노드 수다. P가 고정된 단순 분포에 한해서 절차식 저장을 O(1)이라고 부를 수 있다. 임의 메시나 복잡한 마스크까지 상수 크기인 것은 아니다.

하이브리드가 O(K)만큼 작게 저장되어도 N개를 펼쳐 재생하면 생성 비용은 단순 표본기의 경우 O(N+K)다. 생성기 최적화·충돌·전역 상호작용은 별도 비용이며 위 표에 포함하지 않았다. 렌더 비용에는 선분 수와 화면 중첩도 추가된다.

좌표 세 성분을 32비트로 저장하면 숫자 데이터만 `12N 바이트`다. JSON에는 문자·키·ID·구분자 비용이 추가된다. 하이브리드는 `생성기 크기 + K × (ID·수정 속성 인코딩 크기)`다. K가 N에 가까우면 명시 배열이 더 간단할 수 있다.

F개 프레임의 N개 상태를 저장하는 O(FN) 원본은 불필요하다. 되감기·탐색은 결정적 재계산이나 선택적 체크포인트로 처리한다. 체크포인트는 자산·런타임 버전과 환경을 키로 갖는 재생 캐시다.

### 작은 가상 JSON 예시

**효과 자산의 제안 스키마**다. 좌표·속도는 가상 단위, `style`은 렌더 재질이다. 프로필은 버전 고정 자산이며 실제 제조와 대응하지 않는다.

```json
{
  "schema": "virtual-fireworks-asset/1",
  "id": "bloom-A", "revision": 1,
  "space": "RH-Yup-Zfront-unitRadius/1", "componentId": "lights",
  "distribution": {
    "role": "initial-position", "shape": "sphere-surface",
    "radius": 0.06, "count": 96, "seed": "layout-A",
    "sampler": "uniform-area-prefix/1"
  },
  "motion": {
    "profile": "virtual-outward/1", "directionSource": "base-sample",
    "relativeSpeedRange": [0.8, 1.0]
  },
  "appearance": {
    "style": "amber-soft/1", "trail": "fading-ribbon/1",
    "brightnessOverPhase": [[0, 0], [0.1, 1], [1, 0]]
  },
  "overrides": {
    "lights:17": {
      "positionMode": "absolute-local",
      "position": [0.02, 0.04, 0], "style": "rose-soft/1"
    }
  }
}
```

`lights:17`은 지속 생성 순번이다. 방향은 원래 표본을 읽어 위치 override와 독립이다. 타임라인은 `bloom-A@1`을 참조해 발사대·시각·재생 길이를 지정한다. 배치 seed와 인스턴스 seed를 분리하고 난수·ID 정책을 버전에 고정한다.

렌더 해상도가 낮아져도 의미 ID·생성 사건은 유지한다. 장식 생략과 운동 개체 삭제는 다르다. 장식에 부모 ID를 연결하되 모든 리본 정점을 영구 편집 객체로 만들지는 않는다.

## 7. ‘정확하다’를 네 가지로 나누어 검증하기

다음은 **검증 제안**이다. 수용 오차는 효과·관람 조건별로 사전 정의하고 네 기준을 따로 판정한다.

| 기준 | 필요한 관찰 자료·시험 | 비교할 것 | 이것만으로 입증되지 않는 것 |
| --- | --- | --- | --- |
| 정면 모양 | 기준 카메라와 시점이 정해진 짧은 노출 영상; 예술 모드는 목표 이미지 | 윤곽, 빈 영역, 중심, 방사상 밝기 분포 | 깊이 구조, 전체 시간 과정 |
| 시간별 펼침·잔광 | 프레임률과 노출을 아는 연속 영상; 분기는 충분한 시간 해상도의 자료 | 중심 이동, 펼침 곡선, 밝기 감쇠, 가지 생성 순서, 꼬리 잔존 | 미지의 카메라 처리까지 제거한 고유 발광 특성 |
| 다른 시점의 형태 | 같은 사건을 동기화·보정하여 촬영한 복수 시점; 가상 장면 카메라 회전 | 대응 궤적, 깊이·가림 관계, 시점별 투영의 일관성 | 서로 다른 반복 촬영만으로 동일 3D 사건을 복원했다는 주장 |
| 반복 재생 동일성 | 같은 원본·버전·seed·환경으로 반복 및 중간 탐색 재생 | 상태 비교, 생성 사건 로그, 허용 오차 내 영상 차이 | 실제 불꽃과 닮았다는 사실 |

구형은 방사상 분포·펼침, 꼬리는 잔존·벌어짐, 분기는 연결·발생 순서, 연속 효과는 생성 밀도·수명을 검증한다. 집합은 총 밝기·공간 밀도·시간 변동을 비교하며 생략한 개별 궤적의 정확성을 주장하지 않는다.

### 영상에서 알 수 없는 것

**[문헌]** PBRT §5.4는 센서가 노출 시간과 면적에 걸쳐 빛을 누적하며, 노출·렌즈·감도가 결과에 영향을 준다고 설명한다. [R10] **[추론]** 따라서 장노출의 긴 선을 그 순간 공간에 실제로 존재하는 긴 발광체라고 볼 수 없다. 한 개체가 이동한 선과 여러 개체가 남긴 선도 단일 사진에서는 구별되지 않을 수 있다.

단안 영상은 깊이와 실제 크기·거리를 일반적으로 유일하게 정하지 못한다. 같은 화면 궤적을 만드는 여러 3D 운동이 가능하다. 미지의 노출, 자동 밝기, 화이트밸런스, 포화, 후처리까지 섞이면 픽셀 밝기를 고유 밝기나 크기로 환산할 수 없다. 렌즈의 빛 번짐과 bloom도 발광체의 실제 외곽이 아니다. 가려진 개체와 검출되지 않은 어두운 개체의 수 역시 직접 셀 수 없다.

카메라 조건이 불명확하면 윤곽·상대적 시간 순서로 주장을 제한하고 노출·검출 임계값 민감도를 기록한다. 공개 영상이나 정식 공연의 안전한 관람 촬영을 사용하며 제작 실험은 요구하지 않는다.

동일 seed는 재생 동일성의 일부일 뿐이다. 시간 적분 간격, 사건 처리 순서, 난수 변환, 자산과 환경 버전도 고정해야 한다. 프레임률이 달라도 동일한 시뮬레이션 시간축을 사용하고, 장식용 난수 소비가 운동용 난수를 바꾸지 않게 한다. 플랫폼 간 픽셀의 비트 단위 동일성은 별도 검증 대상이다. 상태의 허용 오차와 영상의 허용 차이를 나눠 정의한다.

## 8. 남은 검증 질문과 권고

**[검증 가설 1: 꼬리 단순화]** 리본만 사용한 모델과 독립 자식 불티를 둔 모델의 차이가 어떤 거리·노출·카메라 이동에서 드러나는가? 관찰 가능한 차이로 상세 상태의 필요성을 정한다.

**[검증 가설 2: 편집 지속성]** 개수 증감·정렬·공용 외관 수정·효과 이동 뒤에도 기존 override가 같은 개체와 의도에 남는가? ID 보존율과 함께 절대 위치·상대 오프셋의 의미 보존을 확인한다.

**[검증 가설 3: 분기와 집합화]** 어떤 효과는 가지 위상만 유지해도 충분하고, 어떤 효과는 독립 궤적이 필요한가? 총 밝기를 맞춘 상태에서 분기 순서와 공간 밀도의 차이를 비교한다.

**[검증 가설 4: 두 종류의 모양 정확성]** 목표 정면 이미지에 잘 맞춘 설정이 카메라 회전과 시간 이동에서도 타당한가? 관측 지향 모드와 형상 제어 모드를 별도로 평가한다.

**발광체·생성기·분기는 의미 모델, 독립 운동 개체는 상태 모델, 꼬리·발광 표본은 렌더 모델로 둔다.** 버전 고정 절차식·희소 override와 명시 좌표 고정을 지원한다. 보편적인 최소 입도·질량값을 정하는 결론은 아니다.
