# Star Studio 화면 구성

2026-09-06, v2. 기존 `studio-concept.png`의 어두운 무대와 앰버 색상을 유지하면서 사용자 요청에 따라 두 작업 화면으로 분리했다.

## 불꽃 만들기

왼쪽은 완성한 불꽃 보관함과 읽기 전용 모양 프리셋이다. 중앙은 Three.js 미리보기이며 전체 불꽃·선택 레이어·발광체 하나를 전환한다. 하단의 작은 재생 컨트롤은 미리보기 시간만 다룬다. 공연 타임라인은 이 화면에 표시하지 않는다.

오른쪽은 현재 불꽃 이름, 독립 편집 범위, 레이어 목록, 패턴/발광체/발사 탭이다. 레이어를 추가/숨김/삭제할 수 있다. 패턴 탭은 모양·개수·퍼짐·회전·지연과 폭발의 초기 속도/강조 시간/감속을 다룬다. 발광체 탭은 프리셋 복사와 자체 외형을 다룬다. 발사 탭은 높이와 상승 시간을 다룬다.

공연 큐에서 상세 편집으로 들어오면 ‘이 큐만 편집 중’과 ‘공연으로 돌아가기’를 표시한다. 설정의 범위는 색이나 선택 강조만으로 전달하지 않고 문장으로 설명한다.

## 공연 편집

같은 보관함에서 불꽃을 드래그해 발사대별 타임라인에 배치한다. 중앙 위에는 공연 미리보기, 중앙 아래에는 전용 타임라인 작업 영역이 있다. 오른쪽 큐/발사대 설정 패널은 세로 전체를 사용해 높이·상승 시간·폭발 시각이 한눈에 보이게 한다. 탭 전환 시 캔버스와 WebGL 컨텍스트를 새로 만들지 않는다.

큐 블록의 앞부분은 상승 구간, 이후는 확장과 잔광까지의 전체 구간이다. 겹치는 큐는 세로로 나누고 발사대 이름은 가로 스크롤 중 고정한다. 시간 눈금은 세로 스크롤 중 고정한다. 가로 확대와 내부 스크롤로 많은 발사대/큐를 다룬다.

큐 설정은 이름, 발사대, 발사 시각, 높이, 상승 시간, 첫 폭발 시각, 잔광 종료 시각을 보여준다. 불꽃 상세 편집과 보관함으로 저장, 복사/복제/삭제를 제공한다. 큐 추가는 사용할 불꽃과 발사대/시각을 선택한다. 순차 배치는 불꽃 선택 순서·발사대 방향·시작·간격·개수를 한 번에 설정한다.

## 언어, 도움말, 작은 화면

ko/en을 헤더에서 전환한다. 보조 레이블, 오류, 접근성 이름, 모든 도움말도 전환한다. 작성된 불꽃/큐 이름은 유지한다. 세부 정책은 [다국어 정책](../architecture/i18n-policy.ko.md)을 따른다.

도움말은 각 필드 옆에 배치하고 무엇을 조절하는지, 값에 따라 무엇이 달라지는지, 편집 영향 범위를 설명한다. hover/focus/click으로 열고 Escape로 닫는다. 대화상자는 배경과 구별하고 키보드 포커스를 내부에 유지한다.

800px 이하에서는 상단 두 줄 헤더, 캔버스, 공연 화면의 타임라인, 라이브러리/설정 선택으로 구성한다. 패널은 세로 스크롤을 허용한다. 터치에서는 큐 추가/상세 설정으로 드래그와 동일한 결과를 만들 수 있다. 3D 효과는 Three.js, 패널과 도움말 같은 일반 UI는 CSS로 표현한다.
